# MM7 3D batches

Every MM7 creature that needs a 3D model, in thirteen batches, one Claude session each. Batches A–L build new models
(61 creatures); batch M gives ten more an MM7-coloured copy of an existing MM8 model.
Point each session at its batch file. None of these models are installed: every batch keeps its work in its own
creature projects until the user says otherwise.

| Batch | Theme | Creatures |
|---|---|---|
| [A](BATCH_A.md) | Human warriors | Fighter Chain, Fighter Leather, Fighter Plate, Swordsman, Archer |
| [B](BATCH_B.md) | Robed casters | Cleric of the Moon, Cleric of the Sun, Mage, Warlock, Monk |
| [C](BATCH_C.md) | Elves, dwarves and giants | Elf Archer, Elf Spearman, Dwarf, Thief, Titan |
| [D](BATCH_D.md) | Undead and non-human humanoids | Skeleton Warrior, Wight, Lich, Ghoul, Troglodyte |
| [E](BATCH_E.md) | Beasts | Behemoth, Griffin, Manticore, Spider, Rat |
| [F](BATCH_F.md) | Humanoid monsters and casters | Devil, Goblin, Necromancer, Vampire, Zombie |
| [G](BATCH_G.md) | Winged and floating humanoids | Angel, Gargoyle, Harpy, Genie, Ghost |
| [H](BATCH_H.md) | Flying creatures | Roc, Bat, Dragonfly, Beholder, Robot |
| [I](BATCH_I.md) | Large and unusual bodies | Hydra, Medusa, Ooze, Treant, Golem |
| [J](BATCH_J.md) | Peasants: dwarves, elves and goblin men | Peasant Dwarf Male, Peasant Dwarf Female, Peasant Elf Male, Peasant Elf Female, Peasant Goblin Male |
| [K](BATCH_K.md) | Peasants: humans and goblin women | Peasant Human1 Male, Peasant Human1 Female, Peasant Human2 Male, Peasant Human2 Female, Peasant Goblin Female |

## Not in these batches

Nothing: with L and M every MM7 creature is covered. Roc (batch H) turned out to be the MM8 Thunderbird body and was
done the batch-M way.

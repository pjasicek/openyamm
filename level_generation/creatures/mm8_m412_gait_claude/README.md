# MM8 m412 gait review viewer

Browser review of the 2026-10-21 `Walk2` and `Jog` clips against the installed `Walking` and `Running`
(export with props baked flat, tier A texture). Built by `../mm8_pirates_gait_claude/scripts/build_viewers.py`; method,
gates and bindings in [../mm8_pirates_gait_claude/README.md](../mm8_pirates_gait_claude/README.md). Recordings:
`review/playback/` (normal and half speed, `python3 tools/run_creature_review.py --project
level_generation/creatures/mm8_m412_gait_claude playback`), stills `review/playback_sheet.png` (rows Walking, Walk2,
Running, Jog).

# MM8 Raven Man restoration

Validated staging package for all 140 native files: 135 unique restored poses and five exact native pixel aliases (`xx0..4` reuse `xa0..4`). Includes 130 referenced files, ten stored orphan files, all five stored views and eight logical directions with native mirrors. Original source assets are unchanged; nothing is installed in gameplay.

Open `viewer.html` directly for native/restored comparison, all stored poses, native animation timing, the green base palette 585 and deterministic blue 586 / burgundy 587 variants. `manifest.json` contains placement and animation bindings; `animations.json` and `variants.json` expose the same metadata separately.

The package has five RGBA8 atlas pages and five matching R8 coverage pages at two pixels per logical pixel. Logical 256×256 canvases, native anchors, frame durations, playback modes and mirrors are retained. Five aliases share atlas rectangles while preserving their native file names and bindings. Base plus mask storage is 91,640,320 decoded bytes (73,312,256 RGBA8 + 18,328,064 R8), including 24,887,835 bytes of packing overhead. Pages use 16-pixel gutters, a three-pixel hidden RGB/coverage bleed and no mipmaps.

Artwork was generated with the built-in imagegen tool. Raw outputs, exact prompts, reference hashes, the rejected first identity, accepted identity checkpoint and targeted flight-wing correction are retained. Each action/view sheet uses a common native layout transform. Reviewed row corrections repair demonstrated displacement in three death sheets and two reaction sheets. Registration is frozen in `batches.json`; poses are never independently fitted or normalized to equal heights.

Native tonal distributions are restored through identity-frozen material color tables on enhanced RGB. The earlier spatial color transfer was rejected because it crossed the side-view head/wing boundary. Enhanced green component support and reviewed equipment permission regions protect feathers and talons from green contamination; RGB-only cleanup preserves luminance and alpha. Palette coverage is computed on enhanced artwork with native palette samples, selective equipment support and interior cool-metal coverage. Original pixel masks are not resized or transferred. The base palette bypass is exact and variants retain identical alpha and placement.

Validation includes all 21 native/registered contacts, 21 native/final contacts, 21 three-palette/mask contacts, magnified final contours on light/dark backgrounds, exact crop/atlas reconstruction, all source and palette hashes, all five alias comparisons in all palettes, and the actual offline viewer. The browser decoded 420 variants, selected all 140 stored poses and checked 192 animation tracks at 1,224 timing boundaries, including loop/hold behavior. Native low-canvas fall cutoffs remain native; no new crop was introduced. Every recorded contour stage has zero excess over its measured native per-frame opponent-color allowances; visual inspection supplements those metrics.

To revise: retain the accepted raw outputs and run `python3 level_generation/creatures/mm8_m584/rebuild.py` from the repository root. Review the regenerated contacts and changed material support, run `browser_checks.py` through the authorized offline wrapper, renew `review/decision.json` with hashes of the reviewed evidence, then run `finalize.py` and `inventory_remaining.py`. Rebuilding does not automatically accept changed artwork. `review/acceptance.json` seals the delivered artifact hashes; a manifest alone is not completion.

Scope: generate five reference images in this directory from original native sprites. No Meshy submissions before all five pass.

Input: ../references_native/standing_five_views.png is native anatomy and tier-A palette authority. Attack/motion sheets provide jaw construction evidence. Generated unseen geometry is inference.

Deliverables: 00_three_quarter.png, 01_front.png, 02_back.png, 03_left.png (snout toward image right), 04_right.png (snout toward image left). Each is one unresized 1536x1024 transparent image-generation return. Freeze the selected primary and use it plus native evidence for the other four.

Pose: lower snake body nearly straight behind, raised J neck, compact feather wings spread, head fins separated. No legs, coils, bat membranes, equipment or enlarged wings. Tier A: violet scales, yellow belly, orange snout, blue-purple/orange head fins, purple/red/gold feather wings, small red-purple tail fan.

Checks: compare all views with native anatomy and palette, paired fin/wing counts, head/body ratios, same pose, left/right consistency, unclipped margins, true alpha and actual pixel dimensions. One targeted correction for a failed view; unresolved mismatches stay visible in progress. Save prompts, input/output hashes, raw return locations and selection reasons in generation_runs.json.

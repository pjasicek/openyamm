| Misty Islands (`oute2`) | Adventure |
| New Sorpigal (`oute3`) | Odyssey |

Ships derive from the five installed BModels per assembly, with their native orientation and coordinates.
[ships.json](ships.json) records model indices, native bounds and projected x2 bounds.

The [approved recipe](approved_recipe.json) and [noise recipe](approved_noise.json) are byte-identical to
the prior approved Blender settings: 2048×2048 Cycles masters, 64 samples, denoising off, separate terrain/object
layers, northwest warm sun, blue fill, 85% smooth terrain normals, light terrain grain and one Lanczos resize
to 1024×1024. Native XY bounds remain ±32,768. New Sorpigal was rendered from current geometry rather than
copying the historical pilot image. The original pilot scene remains the unchanged lighting/camera template.

Static terrain and BModels are included. Sprite vegetation, actors, animated water and dynamic event state
remain outside the approved capture technique. Native coastline shapes and repeated water textures are retained.

Publication records the current regeneration request and assistant review under the previously approved recipe.
It does not claim individual user review of these new renders. [accepted.json](accepted.json) retains this
15-map revision; the authoritative index is [accepted_icons.json](../../ui/hud_inventory/accepted_icons.json).

Publication uses frozen catalog/layout and accepted artifact evidence, as the existing installer does.
Unrelated live HUD authoring inputs remain enforced by the generation queue and were not reconciled or edited.
Seven input-reconciliation tests and two accepted-dependency/layout tests passed.

## Commands used

From the OpenYAMM repository root, before this revision was accepted:

```sh
python3 -B level_generation/minimaps/prepare.py --world mm6 --workspace level_generation/minimaps/mm6_ships_20261004
blender --background --factory-startup --python-exit-code 1 --python level_generation/minimaps/render.py -- --world mm6 --workspace level_generation/minimaps/mm6_ships_20261004
python3 -B level_generation/minimaps/finish.py --workspace level_generation/minimaps/mm6_ships_20261004 --follow
python3 -B level_generation/minimaps/validate.py --workspace level_generation/minimaps/mm6_ships_20261004
```

After the retained visual review:

```sh
python3 -B level_generation/minimaps/publish.py --workspace level_generation/minimaps/mm6_ships_20261004 --apply
python3 -B level_generation/ui/hud_inventory/deploy_icons.py --install
python3 -B level_generation/ui/hud_inventory/deploy_icons.py --check
node level_generation/minimaps/test_browser.mjs level_generation/minimaps/mm6_ships_20261004
```

Use a new workspace for future geometry revisions: preparation refuses to overwrite this accepted package.
Copy the approved recipe/noise files, record the new request and follow the [common workflow](../README.md).
[pipeline.json](pipeline.json) pins the scripts and pilot template used by this revision.
[runtime_tour.yml](runtime_tour.yml) and [runtime_check/run.json](runtime_check/run.json) retain the native check.

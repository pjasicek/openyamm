ORIGINAL CONTENT

The layout carries through.

Centred inspector titles, original Type and Value lines, the familiar stat groups, award colours, rest actions and quick-reference footer. Hold RMB to inspect an inventory item; release to close.

TYPE & COLOUR

Keep the original font roles.

Arrus, Create, Lucida, Comic and Smallnum retain their existing jobs. Fondamento stays on buttons. Ivory for ordinary text; blue for upgradeable skills; green for bonuses and available points; coral for penalties; amber for low HP/SP.

What is real, what is proposed, and what has been preserved

The full-screen base reuses the accepted Carved Obsidian frame. The gameplay base reuses the approved Obsidian HUD. Item art, paperdoll, portraits, rest sky, hourglass and spell illustrations come from real project assets. The goblin is an existing restored sprite. Values and sample interactions are illustrative.

The inventory uses its authoritative 14 × 9 grid at offset (7, 32), size 448 × 288 in the 640 × 480 composition. The prototype restyles cells inside that rectangle. Its item arrangement is a visual fixture. Character pages retain the equipment column and lower navigation. Quick reference retains all fourteen data rows.

The shared border and comparison vellum were generated with built-in imagegen in proposal 01. Buff illustrations are unmodified installed PNGs, shown through per-icon clipping paths which exclude lettering, then fitted into equal icon boxes. Runtime code, mounted assets and saves are unchanged.

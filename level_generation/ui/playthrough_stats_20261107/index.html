Playthrough statistics

Mockups for a read-only Statistics screen in the Carved Obsidian style: the quick-reference surface, native Lucida, Arrus, Create and Smallnum fonts, Fondamento buttons and the shared inspect frame. Every number is one consistent sample playthrough. On the live Overview, hold the right mouse button on a line to see its breakdown, the way stats and skills are inspected.

1. Top bar: a fifth icon

The command strip grows from four to five 30-unit slots (bar 268 to 298 logical wide). Hover shows the usual status text with the key. Default key F1: every letter is already bound.

2. Overview (live: hold right mouse on a line)

Seven groups, 26 lines, nothing that needs explaining. Gold marks rates and records, red marks losses. The party bar's empty right panel shows this session only, since the game was started or a save was loaded.

3. Party

Per member, laid out like Quick Reference. The highest value in each row is gold; zero is a dash. Former members and allies are summarised underneath so the totals still add up.

4. Breakdown: Experience earned

Monsters, quests and events, other. Main numbers are this save's timeline, so a quickload never counts a replayed fight twice; the last line adds play later undone by loading, from the playthrough's lifetime file.

5. Breakdown: Monsters killed

By method, the five most-slain kinds and the strongest foe. The full kill list per monster kind stays in the file for a later bestiary page, not on this screen.

6. Breakdown: Damage dealt

By damage school, the only breakdown that uses bars. Colours follow the magic schools.

7. Breakdown: Deaths

By member, deadliest causes and the last three deaths with place and game day.

8. Breakdown: Time played

Sessions, time per continent, and real time undone by loading (lifetime minus this timeline).

9. A save from before statistics

Loading an older save starts a new record from that point and says so in the header, rather than inventing a history. The playthrough identifier is written into every later save.

New Sorpigal — terrain reference catalogue

49 native terrain tiles · 12 exact shoreline alpha masks · 14 water animation frames. Prepared from MM6 oute3.odm for later image generation.

Readme · Full catalogue JSON · Tile inventory CSV · Prepared imagegen jobs · Transition instructions

Grass ↔ dirt; rock ↔ dirt; road sits on dirt; shore overlays animated water. Only shorelines have true alpha. Opaque grass/rock/road mixtures still need reviewed material masks. Reference sheets are labelled; individual PNG inputs are unlabelled. No images have been regenerated.


Native terrain, north up; no geometry or lighting.

cyan shores, yellow roads.

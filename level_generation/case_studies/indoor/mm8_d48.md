## Layout and visual reading

A large irregular cavern narrows into a bent connector and smaller end pockets. Sloping wall/roof bands create enclosure without uniformly vertical walls. Three occupied sectors and two portals provide a compact but real visibility graph.

## Apply to a new map

Use this as the initial end-to-end template: original three-space cave, actual texture keys/UV scale, explicit portals, one chest, one house and one exit with complete Lua bindings. If the new brief requests two houses, add a second registered identity rather than reusing the exit event.

## Follow-up review

Walk the bend both ways, target all chest surfaces consistently, enter the house and return outside, and test the actor/encounter population. There are no explicit BLV lights and sector ambient is 22; judge final lighting in runtime. Inspect 256-pixel cave textures alongside 64-pixel chest and 16-pixel solid textures to catch fixed-256 UV errors.

Scope runtime checks to new mechanisms or unresolved behavior using the [review policy](../../REVIEW_CHECKLIST.md).

These are review suggestions, not gameplay tests executed by this survey.

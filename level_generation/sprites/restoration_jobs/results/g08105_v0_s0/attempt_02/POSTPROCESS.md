# Native tone restoration

Run queue.py process g08105_v0_s0 without adjustment; then this directory's restore_native_tone.py; then queue.py check g08105_v0_s0. Native opaque RGB grade preserves alpha and registration. before_tone retains ungraded final.

The exposed trunk below native y200 is graded separately from the canopy to avoid a purple bark cast. Both regions use native colors; no geometry or alpha changes.

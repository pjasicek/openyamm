# MAW audit, 2026-10-24

A second pass over the MAW ruleset against MAW `ef23ee17`, and over Standard against git `HEAD` (`7fdb25667`, the last
commit before the MAW work). Thirteen reviewers each took one area; everything already in [DEVIATIONS.md](DEVIATIONS.md)
or [GAPS.md](GAPS.md) was excluded, except GAPS rows marked done whose implementation is wrong. The per-area write-ups,
with MAW and OpenYAMM `file:line` references, a suggested fix per finding and a "checked and matching" list, are in
[audit_20261024/](audit_20261024/). Findings reported by several reviewers are merged below; their ids are kept so the
details can be looked up.

Nothing in the code or data was changed by this audit.

## How it was checked

- Reading: every finding was traced on both sides. "Verified" below means re-read by hand after the reviewers.
- Tests on a private build of the working tree (built outside the repository at 21:00 on 2026-10-24; the tree was
  still changing under other sessions): 2086 unit tests, 7 fail, none from the MAW work (actor bindings, LOD,
  Ogre impact timing, MM6 flour sack text, mercenary equipment). The flour-sack test also fails with HEAD's data; the
  mercenary one is most likely the technology-skill change, which shifts the shuffle (`isTechnologySkill` skip in
  `MercenaryRecruitmentRuntime.cpp`), not the ruleset seam (its Standard methods reproduce HEAD).
- Scenarios: 53 run on the working-tree build and on a build of HEAD with HEAD's data. Every Standard scenario that
  passes at HEAD passes now; the MM6 recorded playthrough and probes fail at the same step in both builds ("A Lonely
  Knight" at trace line 70, missing party fixtures), so they predate MAW. Two ruleset scenarios failed only because the
  tree moved on after the build (`maw_content` uses a new `dimension_door` key; `combat_log`).

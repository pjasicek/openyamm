# X5 Winterkill Tundra, L4 (2026-11-20, A6)

Built from the approved L1 mock-up (`../L1`, board `level_generation/xeen_art/phase2/x5/board_x5.png`) with the
decider's changes D-6.1, D-6.3, D-6.5 and D-4 (`devdocs/xeen/DECISIONS.md`). Map file `xeen_x5.odm`, map_stats 9103,
`world: xeen`, `continent: 6`, music 47, treasure 3, lock 6 / trap 3. Q-C6's qbits are A3's (112121-112127).

## How it is written

Every project file of L2-L4 is written by `output/studio_cal/x5/tools/gen.py` (L1 stays the approved mock-up; L2 and
L3 are the same plan without and with the sketch). Run `output/studio_cal/x5/v.sh [--install]`: generate, fmt,
validate L2-L4, build into `output/studio_cal/x5/build`, X1's `measure.py` and `dress_check.py`; with `--install`
into `assets_dev` and the terrain weights (`tools/terrain_materials.py weights`; the world's liquid edges are shared
with X1/X2 and are not regenerated by this script). Other tools in `output/studio_cal/x5/tools/`: `gen_walk.py`
(`playtest.yml` from the build), `gen_hostility_x5.py` (`playtest_hostility.yml` from the shared generator),
`view.py` (a hillshade of the built heights), `tour.py` and `sheet.py` (engine screenshot tours and contact sheets;
`look.sh <set> <label>` installs and tours), `walk.sh` (a scenario headless against `assets_dev`, `--world xeen`).
Minimap: `output/studio_cal/x5/present/redo_minimap.sh` (X1's scripts; `ice_minimap.py` turns the sand tiles' yellow to
the ice's blue-grey, since the minimap draws native tiles).
